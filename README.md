# BANG! 터치 튜토리얼

뱅 보드게임을 처음 접하는 사용자를 위한 한국어 터치 튜토리얼입니다.
기존 공개 설명서와 독립된 로컬 버전입니다.

## 실행

Node.js 설치 후 이 폴더에서 실행하세요.

```sh
node serve.cjs
```

브라우저에서 http://127.0.0.1:8899/ 에 접속합니다.
Windows에서는 start-local.cmd를 실행해도 됩니다.

## 구성

- 인원 선택: 4~7명, 인원별 역할 수 반영
- 서부 소개와 역할별 승리 조건
- 개인 판, 카드 분류, 역할·인물·손패 배분 모션
- 내 차례의 흐름
- 기본 규칙: 공격·방어 / 회복 / 감옥·다이너마이트 / 강탈·캣 벌로우
- 탈락과 보상·벌칙

화면 터치와 다음·이전 버튼으로 진행하고, 목차와 주제 버튼으로 이동합니다.
챕터 전환 효과, 판정 카드 뽑기·뒤집기·버리기 모션, 모션 줄이기 설정을 지원합니다.
서버 없이 파일을 직접 열면 카드 자료를 불러올 수 없으므로 로컬 서버를 사용하세요.

## 파일

- index.html, tutorial.js, tutorial.css: 튜토리얼 본체
- home-original.*: 이전 홈 화면
- setup-original.*: 세팅 화면과 카드 배분 모션
- assets/: 카드 이미지·개인 판·배경·글꼴
- serve.cjs: 외부 의존성 없는 로컬 서버

## 자료와 글꼴

카드·게임 이미지의 권리는 각 권리자에게 있습니다. 자료 출처는 assets/cards.json에 포함되어 있습니다.
이 저장소의 코드는 이미지의 재배포 권리를 부여하지 않습니다.
페이퍼로지 글꼴: https://github.com/fonts-archive/Paperlogy
KoPub 바탕 글꼴: assets/kopub-batang-OFL.txt 참조.
